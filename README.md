# CSWA

A collection of solidworks CSWA practice models recreated (in solidworks) for learning and skill development.

## References

- CSWA practice models (named `CSWA_10_<practice model no.>`) are based on official SolidWorks CSWA practice drawings. The original reference drawings are not included in this repository.
